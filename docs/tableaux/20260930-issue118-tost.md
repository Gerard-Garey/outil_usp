### C3 -- TOST de la constante : probabilité de conclure à l'équivalence sous le modèle ajusté, T = 8

Statut : **constat de simulation sous le modèle réglementaire ajusté** (constante a = 0 vraie ; propriété du plan de volumes du jeu, non du seul T). Jeux y* simulés par usp_simuler() au modèle ajusté au jeu observé (x fixe), sans réajustement ; p = test_tost_intercept(x, y*, theta = 0,10)$p (marge Δ = 0,10 × moyenne de y*, valeur par défaut de run_engine()) ; conclusion d'équivalence si p < α.
