### C3 -- TOST de la constante : probabilité de conclure à l'équivalence sous le modèle ajusté, T = 8

Statut : **constat de simulation sous le modèle réglementaire ajusté** (constante a = 0 vraie ; propriété du plan de volumes du jeu, non du seul T). Jeux y* simulés par usp_simuler() au modèle ajusté au jeu observé (x fixe), chacun réajusté par usp_ajuster(x, y*) comme dans run_engine() ; p = test_tost_intercept(x, y*, fit*$pi, theta = 0,10)$p, modèle auxiliaire pondéré aux poids GLS du réajustement (#215) (marge Δ = 0,10 × moyenne de y*, valeur par défaut de run_engine()) ; conclusion d'équivalence si p < α ; taux sur les réajustements réussis, échecs comptés. Conclure exige Δ − |â| > t(1 − α, T − 2) se(â), donc se(â)/Δ < 1/t(1 − α, T − 2) (condition nécessaire) ; se(â) croît avec le levier pondéré de l'origine x̄_w²/S_xx,w. Avant #215 (TOST MCO, sans réajustement) : docs/tableaux/20260930-issue118-tost.md.
