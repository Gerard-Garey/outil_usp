# Essai Codex Cloud — branche jetable

Branche et PR créées le 28/09/2026 à la demande du mainteneur, pour éprouver
le lancement de Codex Cloud par un commentaire `@codex` sur une PR : où le
livrable est remis (réponse du bot, commentaire complet ou lien vers la
tâche), si Codex peut pousser sur la branche de la PR ou en ouvre une autre,
et comment une tâche suivante relit les livrables précédents.

**Ne pas fusionner.** La PR sera fermée et la branche supprimée après l'essai.
Aucun fichier du moteur, des tests, de la documentation LaTeX ni des
références n'est touché.
